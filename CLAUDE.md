
## Team knowledge

Team decisions, gotchas, rejected approaches and conventions live in `docs/knowledge/`.
Before working in an area, read `docs/knowledge/INDEX.md` and the topic files relevant to the task,
and follow them. If the code contradicts a note, point it out to the user instead of silently picking one.
At the end of meaningful work, suggest running `/team-knowledge:share-context` to save anything the team should know.
