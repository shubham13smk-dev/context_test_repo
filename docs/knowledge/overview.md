## What it is

Star Blaster is a single-screen arcade space shooter that runs in a web browser. The player
flies a ship along the bottom of a vertical playfield, shoots waves of enemies falling from the
top, collects power-ups, and survives as long as possible. The game gets harder the longer a run
lasts. A run ends when the player loses all their lives, and the best score ever reached on that
browser is remembered and shown on the game-over screen.

The whole game is one self-contained web page. There is no sign-up, no server, and no installation —
opening the page is the entire experience.

## Who it's for

Young mobile users who don't want to download heavy games and need a quick way to get entertainment without large downloads or installation.

_Updated 2026-11-13 by subs via Knowledge Portal — related: index.html, docs/knowledge/open-questions.md_

## The problem it solves / the goal

Lets users play instantly by visiting the website — no download or installation required — solving the problem of heavy mobile games that take up storage and time to install.

## Current status

Early prototype. The playable game was committed on 2026-11-05 and has since gained a settings screen
with selectable maps, a difficulty setting and keyboard auto-fire. Work so far has come from a
single contributor. A team knowledge base was added on 2026-11-05 and extended on 2026-11-06.
There are no automated tests and no release or hosting setup in the repository.
